## Post

Updated an old .NET tool from CodePlex that I use regularly.

**What it does:**
Adds "Assembly Information" to Windows Explorer's context menu. Right-click any DLL/EXE to see:

• Compilation mode (Debug/Release)
• Target framework
• Assembly identity with versioning
• PE characteristics
• Dependency tree

**Why:**
Needed quick answers without opening ILSpy: "Is this Debug or Release?" "What framework does it target?" "What dependencies does it have?"

**How it works:**
Uses `MetadataLoadContext` for safe inspection without loading assemblies into runtime. No code execution, no file locks, works across all .NET versions.

**History:**
Originally by rockrotem (2008, CodePlex) and Ashutosh Bhawasinka (2011-12). Migrated to GitHub by Jozef Izso (2014).

**Link:** https://github.com/tebjan/AssemblyInformation

Ms-PL license.

Handy for build verification, dependency debugging, or when you're stuck in DLL hell.
